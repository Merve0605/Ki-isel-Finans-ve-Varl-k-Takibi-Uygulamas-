# Ki-isel-Finans-ve-Varl-k-Takibi-Uygulamas-
Siiye banka hesap hareketlerinizi (gelir/gider) ve kasa veya dijital ortamlardaki değerli varlıklarınızı (altın, takı, döviz, kripto vb.) tek bir yerden güvenle kaydetip toplam net varlığınızı anlık olarak takip etmenizi sağlayan Kişisel Finans ve Varlık Takip Uygulamasıdır.
